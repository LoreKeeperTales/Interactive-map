DM-ONLY STAT BLOCKS
-------------------
Every NPC page now includes a hidden combat stat block.

Default password:
DM451

To change the password on an NPC page, search for:
const DM_PASSWORD = "DM451";

and replace DM451 with the password you want.

Important:
This is client-side protection. It hides the statistics from normal viewing,
but anyone deliberately inspecting the HTML/JavaScript source could discover
the password or hidden content. It is suitable for keeping information away
from players during ordinary table use, not for protecting sensitive data.
